v1.0.029 Oct 2026live

The first public release

Everything the Autosage web app does, from your terminal. Install it with uv tool install sagex-cli, or see Install.

Terminal app

  • Full-screen app (sagex): a resources tree (workflows, scripts, vault, recent runs with status, triggers) beside a terminal-style transcript.
  • Run any shell or sagex command with !, with live output, Esc to stop and ↑ ↓ history. Workflow runs draw a live node graph.
  • Switch between server resources and a local workspace folder (F3), cycle shells (F2) and refresh (F5).

Commands

  • auth: log in with an API key stored in your OS keychain; status and logout.
  • list and show: workflows, scripts, runs (with --logs), triggers, vaults, servers and keys, with --json output.
  • render workflow: draw a workflow as a flow tree, from the server or a local file.
  • run script and run workflow: run now and follow live. Ctrl+C stops; logs are saved to the workspace.
  • trigger: create HTTP and schedule triggers, fire, poll, watch the next scheduled run, an invoke cheat sheet, enable / disable, and regenerate secrets.
  • new, push and copy: scaffold, upload and download workflows and scripts; copy run logs.
  • create, update, rename and delete: vaults, servers and keys, plus workflows, scripts and triggers where they apply.
  • syntax: copy-paste JSON snippets for workflow nodes and edges.

Security

  • Secrets are never accepted as flags or written to disk. They're typed at hidden prompts or read from a file you choose.
  • Crash reports never include local variables, so a key can't leak into a traceback.

Configuration

  • SAGEX_API_KEY (a key without the keychain, for CI), SAGEX_API_URL and SAGEX_DEBUG.
