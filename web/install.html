Install SageCode

Up and running in about a minute: install SageCode, log in with your API key, and run your first sagex command.

Before you start

  • An Autosage API key. SageCode is in early access, and keys are issued on request. Ask for one here. Keys start with sgx_.
  • macOS, Linux or Windows, with Python 3.11 or newer. The one-line installer downloads Python for you if you don't have it.
  • An OS keychain to keep the key in. macOS and Windows have one built in; on Linux, SageCode uses Secret Service (GNOME Keyring or KWallet). No keychain, as on a CI runner? Use the SAGEX_API_KEY environment variable instead.

Install and log in

  1. Run the installer

    It installs SageCode as an isolated tool with uv (installing uv first if needed) and puts the sagex command on your PATH.

    $curl -LsSf https://sagecode.web.app/install.sh | sh
    PS>irm https://sagecode.web.app/install.ps1 | iex

    To install a specific version, set SAGEX_VERSION first, for example SAGEX_VERSION=1.0.0.

  2. Open a new terminal and check it

    terminal
    ❯ sagex --versionsagex 1.0.0

  3. Log in with your API key

    Paste the key when asked. It isn't shown as you type, and SageCode checks it with the server before saving it to your OS keychain.

    terminal
    ❯ sagex auth loginsagex is in early access — API keys are issued on request: https://autosagex.web.app/contactPaste your sagex API key: ✓ Logged in — key saved to your OS keychain.

  4. Run your first commands

    terminal
    ❯ sagex list workflow # your workflows, as a table❯ sagex # open the terminal app❯ sagex --help # every command group

    Next, read the guide or browse all the commands.

Other ways to install

SageCode is on PyPI as sagex-cli; the command it installs is sagex. Any Python tool manager works:

ToolCommand
uvuv tool install sagex-cli
pipxpipx install sagex-cli
pippip install sagex-cli (into a virtual environment)
A pinned versionuv tool install sagex-cli==1.0.0

Prefer to read the installer first? It's short: install.sh and install.ps1.

Configuration

SageCode works out of the box. These environment variables change its behaviour when you need to:

VariableWhat it does
SAGEX_API_KEYUse this API key instead of the keychain. It takes precedence over a saved key. Made for CI jobs and machines without a keychain.
SAGEX_API_URLPoint SageCode at a different Autosage server.
SAGEX_DEBUG=1Add connection details to network errors.

Your preferences, such as the workspace folder and the terminal app's shell, are saved in ~/.sagex/config.json. Check your login at any time:

terminal
❯ sagex auth status✓ Logged in to Autosage · key sgx_…VphY

Update or uninstall

Upgrade with the same tool you installed with:

terminal
❯ uv tool upgrade sagex-cli # or: pipx upgrade sagex-cli · pip install -U sagex-cli

To uninstall, log out first so your key is removed from the keychain, then remove the tool:

terminal
❯ sagex auth logoutLogged out — API key removed from your OS keychain.❯ uv tool uninstall sagex-cli

Troubleshooting

You seeWhat to do
sagex: command not foundOpen a new terminal so your PATH is reloaded. Still missing? Run uv tool update-shell, then open another terminal.
That doesn't look like a sagex API keyAPI keys start with sgx_. Copy the whole key and try again.
That key wasn't acceptedThe key is mistyped or has been revoked. Paste it again, or ask for a new one.
No OS keychain is available on this machineSet the key in your environment instead: SAGEX_API_KEY=<your key>.
Not authenticated — your API key is invalid or was revokedRun sagex auth login with a current key.
Unable to reach the Autosage serverCheck your internet connection and try again. For details, run the command again with SAGEX_DEBUG=1.

Something else? Open an issue with the command you ran and what it printed.
